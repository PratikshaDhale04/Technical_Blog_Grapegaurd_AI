# 🍇 GrapeGuard AI
## Smart Prediction and Control of Downy Mildew in Grapes Using Machine Learning

---

## 📌 Overview
GrapeGuard AI is a Machine Learning-based system developed to predict and control **Downy Mildew disease** in grapes at an early stage.  
The system analyzes environmental and crop-related factors such as rainfall, humidity, temperature, and crop growth stage to predict disease risk levels and help farmers take preventive actions.

Downy Mildew is caused by *Plasmopara viticola* and spreads rapidly in warm and humid conditions, causing severe crop damage and financial loss to farmers.

---

## 🎯 Objectives
- Predict grape disease before visible symptoms appear
- Reduce crop damage and production loss
- Minimize excessive pesticide usage
- Support smart and sustainable agriculture
- Assist farmers with data-driven decisions

## 🤖 Machine Learning Algorithms
### 1️⃣ Support Vector Machine (SVM)
Used for classification of disease risk levels.

### 2️⃣ Random Forest
Uses multiple decision trees for accurate prediction.

### 3️⃣ Gradient Boosting
Improves prediction performance using boosting techniques.

---

## 📊 Input Features
The model uses the following parameters:

| Parameter | Description |
|-----------|-------------|
| Rainfall | Rain amount affecting disease spread |
| Humidity | Moisture level in the environment |
| Temperature | Atmospheric temperature |
| Crop Stage | Growth stage of grape plants |
| Historical Data | Previous disease records |

---

## 📈 Output Prediction
The system predicts:
- ✅ Low Risk
- ⚠️ Medium Risk
- ❌ High Risk

---

## 🌿 Disease Control Suggestions
Based on prediction results:
- Field sanitation
- Pruning infected leaves
- Preventive fungicide spraying
- Continuous crop monitoring
